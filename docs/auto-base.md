# 補正データの取得先の自動選択(再検索の条件)

補正データの取得先に「自動」を選ぶと、本体が KUON GEO の公開している基準局の一覧([kuongeo.com](https://kuongeo.com/ja/learn/bases))から、今いる場所の近くの局を探してつなぎます。ここでは、いつ探し直すか、どう選ぶかをまとめます。実装は `src/kuon.cpp` の `kuonCheck()` で、補正データを受ける `taskBaseRecv`(`src/rover.cpp`)が周回ごとに呼びます。

## 探し直す条件

次のどれか一つに当たると探し直します。

| 条件 | 補足 |
|---|---|
| まだ探していない | 自動に切り替えた直後と、起動直後。`kuonReset()` で「未検索」に戻るので、次の機会に探す |
| 前回探した場所から `auto.researchKm` 以上動いた | 既定 1 km。前回の検索時の位置と現在地の距離で判定する |
| いまの局に続けて 3 回つながらなかった | 再接続の失敗ごとに回数が増え、接続できると 0 に戻る(`src/rover.cpp` の `failures`)。このときは、いまの局を候補から除いて探す。回数は `src/kuon.cpp` の `KUON_FAIL_MAX` |

## 探し直さない条件

上の条件に当たっていても、次のどれかに当たる間は見送ります。

| 条件 | 理由 |
|---|---|
| 自動が無効、または Wi-Fi が未接続 | 一覧を取れない |
| 測位できていない(`quality` が 0) | 現在地が要る |
| 前回の検索から 60 秒たっていない | 一覧が取れなかったときや、選んだ局に続けてつながらないときに、連続して探さないための間隔(`KUON_RETRY_MSEC`) |

## 選び方

- 候補は、検索半径 `auto.radiusKm`(既定 40 km)の中で、無料(`fee=N`)、直近の巡回で応答あり(`up=1`)、認証不要(`auth=N`)の局です。rtk2go.com の局は、設定ファイルの `rtk2go.user` と `rtk2go.password` の両方があるときだけ候補に入れます。
- その中で、直近 30 日の応答率が `auto.minRate`(既定 90%)以上の、いちばん近い局を選びます。いちばん近い局が応答するとは限らないので、応答率で絞ります。
- 条件に合う局がなければ、いまの取得先を変えません。シリアルログに `Kuon: no base station (rate >= 90%). Keep the current source` が出ます。
- 選んだ局がいまの局と違うときだけ、`taskBaseRecv` が切断して新しい局につなぎます。選んだ局は `m5f9p.run.json` に保存され(loopTask の `kuonPoll()`)、次の起動でもその局から始めます。

## 設定

設定ファイルの `auto` の節です。既定値は `src/settings.cpp`、範囲は `src/config.cpp` にあります。

| 設定 | 内容 | 既定 | 範囲 |
|---|---|---|---|
| `auto.researchKm` | 前回探した場所から、これだけ動いたら探し直す(km) | 1 | 0〜1000 |
| `auto.radiusKm` | 検索半径(km)。これより遠い局は選ばない | 40 | 0〜2000 |
| `auto.minRate` | 応答率の下限(%)。これ未満の局は選ばない | 90 | 0〜100 |

## 確かめ方

- シリアルログ(`mise run log 30`)に `Kuon:` で始まる行が出ます。近い順の候補 5 件(距離、応答率、ホスト、マウントポイント)と、候補の数、選んだ局です。
- 本体の Corrections のページと、アプリの状況タブに、選んだ局、距離、応答率が出ます。距離は現在地から局までを計算し直した値で、移動すると変わります(応答率は探した時点の値)。
- 基準局の正確な位置は、補正データの中の RTCM 1005 / 1006 メッセージから取ります(一覧の位置は小数 2 桁で、約 1 km の精度しかありません)。補正データが届き始めると、状況タブの「基準局」に緯度経度が出て、距離もその位置で計算し直します。アプリの地図には基準局の位置に三角の印が出て、「基準局」ボタンでそこへ移動できます。取得先を切り替えると、次の 1005 / 1006 が届くまで印は消えます。これは自動選択に限らず、手動で選んだ取得先でも同じです。
- コマンド `status` の応答の `base` に、`auto`(自動かどうか)、`searching`(探している途中か)、`km`(局までの距離)、`rate`(応答率)が入ります。
